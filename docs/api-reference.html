🔌 API Reference

Base URL

All API endpoints are relative to http://localhost:5000/api

Response Format

All endpoints return JSON with the following structure:

{
  "success": boolean,
  "status_code": number,
  "data": {
    // Response data
  }
}

Endpoints

Health Check

GET /health

Check API server status

Example Response:

{
  "success": true,
  "status_code": 200,
  "data": {
    "status": "healthy",
    "service": "PCAP Editor API",
    "timestamp": "2025-12-29T10:30:00.000000"
  }
}

Upload PCAP File

POST /pcap/upload

Upload and parse a PCAP file

Request

Content-Type: multipart/form-data

Parameters:

Name Type Description
file File PCAP or PCAPNG file (max 100MB)

Example Response:

{
  "success": true,
  "status_code": 200,
  "data": {
    "filepath": "uploads/20251229_103000_capture.pcap",
    "filename": "capture.pcap",
    "packet_count": 1250,
    "packets": [...]  // First 100 packets
  }
}

Get Packets List

GET /pcap/packets/<filepath>

Get paginated list of packets

Query Parameters

Name Type Default Description
offset integer 0 Starting packet index
limit integer 100 Number of packets to return

Example

GET /pcap/packets/uploads/20251229_103000_capture.pcap?offset=0&limit=50

Example Response:

{
  "success": true,
  "status_code": 200,
  "data": {
    "total": 1250,
    "offset": 0,
    "limit": 100,
    "packets": [...]
  }
}

Get Packet Details

GET /pcap/packet/<filepath>/<packet_index>

Get detailed information about a specific packet

Path Parameters

Name Type Description
filepath string Path to PCAP file (URL encoded)
packet_index integer Zero-based packet index

Example

GET /pcap/packet/uploads/20251229_103000_capture.pcap/5

Example Response:

{
  "success": true,
  "status_code": 200,
  "data": {
    "index": 5,
    "timestamp": 1609459800.123456,
    "length": 64,
    "layers": "Ether / IP / TCP",
    "src_ip": "192.168.1.100",
    "dst_ip": "10.0.0.1",
    "src_port": 50123,
    "dst_port": 443,
    "flags": "S",
    "payload": "48656c6c6f...",
    "payload_size": 20
  }
}

Modify Packet Payload

PUT /pcap/packet/<filepath>/<packet_index>

Modify the payload of a specific packet

Request Body

{
  "payload": "48656c6c6f20576f726c64",  // Required: hex-encoded payload
  "offset": 0                            // Optional: byte offset (default: 0)
}

Example

PUT /pcap/packet/uploads/20251229_103000_capture.pcap/5

Example Response:

{
  "success": true,
  "status_code": 200,
  "data": {
    "message": "Packet modified successfully"
  }
}

Export PCAP File

GET /pcap/export/<filepath>

Download the PCAP file

Response

Binary PCAP file (mimetype: application/octet-stream)

Error Handling

All errors return appropriate HTTP status codes:

Status Code Description
200 Success
400 Bad Request - Invalid parameters or missing data
404 Not Found - File or packet not found
500 Internal Server Error

Rate Limiting

Currently, there is no rate limiting. Future versions may implement this.

Authentication

The API is currently open with no authentication. For production use, implement appropriate security measures.

Code Examples

Python

import requests

# Upload file
files = {'file': open('capture.pcap', 'rb')}
response = requests.post('http://localhost:5000/api/pcap/upload', files=files)
data = response.json()
filepath = data['data']['filepath']

# Get packet details
packet_response = requests.get(f'http://localhost:5000/api/pcap/packet/{filepath}/0')
packet = packet_response.json()['data']
print(f"Source: {packet['src_ip']}:{packet['src_port']}")
print(f"Destination: {packet['dst_ip']}:{packet['dst_port']}")

JavaScript/Node.js

const axios = require('axios');

async function analyzePacket() {
  try {
    // Get packet details
    const response = await axios.get(
      'http://localhost:5000/api/pcap/packet/uploads/capture.pcap/0'
    );
    
    const packet = response.data.data;
    console.log(`Protocol: ${packet.layers}`);
    console.log(`Payload: ${packet.payload}`);
  } catch (error) {
    console.error('Error:', error.message);
  }
}

analyzePacket();
